# Getting Started with Finance web app

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Available Scripts

### Live  
Visit Live Demo [finance link](https://hoxton.herokuapp.com/)


### Step1 
`Copy the following link and take clone of the github repo`


```
git clone https://github.com/shahabyounas/finance.git

```

### Step2 Install Dependencies in root and /client folders

```
 cd finance and npm install
 
 cd client and npm install
 
 Inside client folder:
 npm start

```

### `npm start`

Runs the app in the development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
